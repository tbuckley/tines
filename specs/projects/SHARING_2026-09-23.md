# Shared project permission decisions — 2026-09-23

This dated decision accompanies Tines/669. It records the owner permission
and recurring-source contract; later slices add membership and attributed
decisions. Historical single-owner specifications remain as records of their
earlier scope.

## Browser authority

Personal permission may be created or changed only by the person's browser
session. A key, including a run key, cannot supply an explicit on or off
choice. Omitted key input in a consent-mode project has no consent side
effect. First sharing is permanent; projects never shared retain their
legacy automation. Structural invalidation on completion, transfer, workflow
replacement, removal or source change is a safety rule, not a key's authority
to choose on behalf of a person.

## Recurring lifetime

The initial recurring issue and later schedule instances have independent
choices. Future permission defaults off. The schedule's `permission_epoch`
changes only for semantic work or effective start changes; the existing
`definition_revision` continues to fence execution definition edits. Rename
and pause/resume do not reset permission. Inherited issue choices retain the
source grant revision and epoch, and admission also checks the live source.
Source off, deletion and semantic change clear only inherited unlaunched
permission; explicit issue choices survive. Re-enabling affects only future
issues. A durable origin snapshot preserves historical provenance without
authorizing execution.

## Attributed member decisions

The completed 669 branch adds accepted-member comments, repair of their own
human and run comments, exact awaiting-human transitions, and own browser
issue/future controls. The owner may moderate project comments; run keys may
repair only a comment made with that exact run key. The author and run remain
immutable while the editor is named separately. Project events occupy one
canonical owner stream row and preserve the member actor; current members
see the same event ID through an allowlisted feed.

Member on is stored with the current membership revision and cannot launch
work in this release. Only the owner's approved agents may be admitted.
Archived nonterminal issues may save an own choice but cannot admit work.
Admitted cancellation retains its live slot until terminal acknowledgement
or established reconciliation. The [proposed 670/712 integration contract](../../docs/shared-project-execution-contract.md)
remains unreviewed until the parent lands and review completes.
